## 2026-11-03：1.2.0 用途与宿主协作

平台发布 `fbfb104`，217 项隔离测试通过，174 个 JavaScript 文件语法检查通过。覆盖用途默认值、主人替换、发布快照、提示词不进入公开字段、MCP 与模型 API 区分、授权预算不扩大以及旧请求重试。用途编辑、保存和恢复在本地桌面与窄屏页面检查；不等同于各客户端端到端实测。

在 Mac mini 使用隔离内存数据库、合成人格和四条合成 Skills，以 deepseek-v4-flash 做两组单次文本方法对照。原始 Skills 与 C.AI MCP 分别耗时：音效 33.6 / 25.4 秒，审稿回应 16.3 / 10.0 秒。输入 token 分别为 333 / 2159、343 / 2169。结果不能证明更省成本或稳定更快：没有重复采样、盲评或宿主执行，且 C.AI 包含平台规则与上下文，两路不保证全部模型参数一致。

MCP 能返回宿主执行步骤与审美选择，但仍有问题：审稿样例混淆回复文件与稿件位置；音效样例给出部分未经素材校准的参数和过于绝对的风格判断。尚未达到“必然比直接读 Skills 更好”的质量结论。另一次独立测试将主人用途替换为最多两句自然对话，返回“那就歇会儿吧。”，未强制输出 SOP。

模型与原始私人资料未写入此仓库；未修改 Hermes 全局模型或生产人格数据。客户端支持边界见 [CLIENTS](CLIENTS.md)。
