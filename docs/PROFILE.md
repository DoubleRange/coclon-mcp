# MCP 个人资料编辑

连接授权可单独选择「不允许 / 查看个人资料 / 查看并编辑草稿」。默认不允许，原有工作密钥不扩权；重新连接并在 REAL 本人页面选择权限后才生效。可只授权资料而不选分身，此时没有任何分身调用权限。

- `real_profile_read`：本人资料栏目、字段、记录、默认简介及最近修改记录。只读权限可能包含本人未公开字段，授权页明确说明。不包含 BLEACHAI 原始人格、分身知识、密钥或其他账号。
- `real_profile_update`：先读取revision，再提交operation_key与changes。支持默认简介字段、记录值、追加栏目/字段/记录及栏目改名；只按本人给定事实编辑。新字段和记录默认不公开，不提供删除、发布、修改公开权限、原始人格或知识库操作。
- `real_profile_restore`：使用本人历史event_id及最新revision恢复一笔修改到草稿；知识库与已发布网站保持。

编辑免费，不触发工作计费。重复操作编号与相同内容返回原结果，不重复写；同编号换内容和并发旧版本409。每笔编辑保留账号、连接、前值、版本和操作编号。撤销连接、过期或账号失效后不能继续读写。Web个人资料和网站草稿继续读取同一记录，公开版本另行由本人发布。

数据库schema13：api_keys.profile_access默认none；profile_edit_events仅存本人私有历史。OAuth/设备授权及手动连接沿用既有登录与撤销机制；新增权限不从客户端自报名称或分身可用范围推断。npx连接器1.2.0包含新工具；旧1.0.1下载地址保留兼容。

交付核对仍启用。DeepSeek使用JSON模式，无问题时只返回issues空数组；有问题必须给出修订，格式错误或上游失败不标成功。创意分镜中明确提出的建议不当作已发生事实，但不能虚构产品已有功能。依据：[JSON输出](https://api-docs.deepseek.com/guides/json_mode/)。
