# 专家分身与原 Skill

REAL提供两个独立入口：

- **调用分身**：MCP委托一个分身，宿主保留自己的模型；API让REAL分身成为宿主的主模型。两者使用REAL的专业方法、知识和人格规则，按账号授权及积分规则调用。接入见[安装说明](./INSTALL.md)和[主模型配置](./MODEL.md)。
- **安装原Skill**：把原项目的方法和资源安装到本地Agent，由本地模型执行。它不包含REAL人格、模型服务或账号授权，也不是安装REAL MCP的前置步骤。

## 获取原项目入口

读取 `REAL_ORIGIN/api/open-skills/PROFESSION_SLUG`，只返回当前公开且可见分身的安装清单。可从REAL专家页或分身页获得对应链接；不要猜测分身标识。

清单包含原项目、Skill名称、资料关系和安装命令，例如：

```sh
npx skills add OWNER/REPO --skill SKILL_NAME
```

该命令使用上游默认分支。清单记录的来源commit是REAL审阅资料的版本，不表示上述安装命令固定到该commit。安装前由用户确认，并按原项目说明检查依赖、许可证与宿主兼容性；复制链接本身不执行安装。

## 公开资料专家

公开网络资料整理的AI分身不是本人账号或官方服务。资料区分本人编写、明确推荐、试用和提及；介绍一个项目不等于认可全部子技能。页面来源用于理解方法和判断依据，不代表专家入驻或授权背书。

公开发现、读取安装清单与获得REAL模型调用权限是不同操作。MCP调用仍须使用已授权账号，并在其可用分身与预算范围内执行。
